    How the momentum model works

    Every protocol in the snapshot that records no token is priced from the snapshot’s own figures. The category’s ratio is the median market-cap-to-TVL of the protocols in that category that already trade, shrunk toward the whole snapshot’s median when the category has few live peers. Base value is TVL times that ratio. Then growth does the ranking, and it compounds: the seven-day TVL change, clamped to −40%..+100%, is raised to the third power, so +18% in a week is worth 1.64x, +100% is worth 8x and −20% is worth 0.51x. A week of +10% or better earns a hot bonus of 1.15x, and a protocol under a year old with no token earns a fresh bonus of 1.10x. Running on more chains adds 5% a chain, up to four extra chains. Last, a size adjustment discounts the giants and lifts the small: the value is multiplied by the square root of $100M over TVL, clamped to 0.25x..2.5x, so the board ranks where the money is moving per dollar already there, not where it already sits. Without it the same giants would hold the top ten whatever they grew, and this would be a size table in a different colour. Nothing here is a prediction that a token launches, or when: the implied value is this entry’s own claim about what a launch would be worth if the money kept moving the way it moved this week.
